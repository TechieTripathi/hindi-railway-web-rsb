{#- Discard / Restore for every `.article-picker` on the page. Shared by the panel's "Choose articles" step and the Advanced articles table. A picker root carries: data-api POST endpoint (/api/selection/) data-view all | selected | excluded — which rows the list should show data-discarded current discarded count data-summary e.g. "{selected} selected · {discarded} discarded" Inside it, by class: .sel-row (with data-key), .sel-status, .row-toggle, .article-pick, .select-visible, [data-selection-action], .restore-all, .sel-summary, .view-empty, .article-table, .showing-count, .selection-error, and optional .view-chip buttons (data-view) that filter in place, and an optional .bulkbar (fixed bottom bar: .bulk-count, .bulk-clear) shown while rows are ticked. For long lists: .text-filter (matches a row's data-text), .source-filter (matches data-source), .preview-toggle (shows the .snip lines) and .view-chip .count badges. The server's reply — every discarded key and both counts — is applied to all rows, so the page can never disagree with what "Write stories" will use. -#}
